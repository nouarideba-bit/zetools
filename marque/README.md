# Logo ZETools

Proposition de logo du 19/11/2026 : **l’écrou ZE**. Un écrou hexagonal jaune chantier, frappé d’un Z anthracite.
L’écrou dit l’outillage et la solidité ; le Z porte le nom ; la forme reste lisible à 16 pixels (icône de navigateur, pictogramme d’application).

| Fichier | Usage |
|---|---|
| `logo-zetools.svg` | Symbole seul : icône du site, avatar des réseaux sociaux, tampon des documents |
| `logo-zetools-horizontal.svg` | Symbole + nom, sur fond clair |
| `logo-zetools-horizontal-fond-sombre.svg` | Symbole + nom, sur fond sombre |

- **Couleurs :** jaune chantier `#f5b700`, anthracite `#23272b`, blanc.
- **Zone de protection :** laisser autour du logo un espace libre égal à la moitié de la hauteur du symbole.
- **Taille minimale :** 16 px de haut pour le symbole, 80 px de large pour la version horizontale.
- **À ne pas faire :** déformer, changer les couleurs, poser le symbole sur un fond jaune.
- Le logo est dessiné en formes simples : il se reproduit à l’identique dans les fiches PDF (`pdf.js`).

À faire avant tout usage public : vérifier la disponibilité du logo et le déposer avec la marque à l’INPI (marque semi-figurative).
